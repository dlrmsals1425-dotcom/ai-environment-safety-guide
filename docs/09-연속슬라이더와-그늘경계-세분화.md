# 연속 슬라이더와 그늘 경계 세분화

2026-09-18 · 시간 슬라이더 끊김 및 각진 경계에 대한 후속 개선.

## 시간 전환

기존에는 시간이 바뀔 때마다 워커를 종료하고 레이어를 제거한 뒤 180ms 대기 후 전체를 재계산했다. 연속 드래그 중 계산이 계속 취소되고 화면도 비었다.

- 날짜·관심구역·건물·지형이 유지되면 같은 워커와 공간 인덱스를 재사용한다. 시간과 해상도만 전달한다.
- 한 작업을 실행하는 동안 다음 요청은 최신 하나만 보관한다. 중간 시각을 모두 줄 세우지 않는다.
- 기존 지면 그늘을 유지하고 이미지 소스의 내용만 갱신한다. 표시 중인 결과의 실제 시각과 요청 시각을 구분한다.
- 조작 중에는 기본 4m 미리보기, 마지막 입력으로부터 220ms 후에는 기본 2m 계산과 경계 세분화를 요청한다. 큰 관심구역은 기존 셀 수 상한에 따라 간격이 커진다.
- 대형 마스크의 픽셀 생성·PNG 인코딩도 OffscreenCanvas를 사용하는 워커로 이동해 화면 스레드를 막는 작업을 줄였다.
- 날짜·구역·자료 변경, 레이어 숨김, 컴포넌트 해제 시에는 이전 장면을 폐기하고 워커·이미지 URL을 정리한다. 다른 지역/날짜의 결과를 남기지 않는다.

이는 결과 갱신의 끊김을 줄이는 방식이며, 매 화면 프레임마다 광선을 모두 재계산하는 60fps GPU 그림자 엔진은 아니다. 계산량과 PC 성능에 따라 이전 결과가 잠시 유지될 수 있다.

## 경계 세분화

1. 기본 2m 격자의 지형·건물 차폐를 계산한다.
2. 주변 8개 셀 중 그늘/햇빛 판정이 다른 셀을 경계 부근으로 식별한다.
3. 해당 셀을 가로·세로 4분할하고, 각 세부 셀의 지면 표고를 읽어 태양 방향 광선을 다시 검사한다. 일반 구역의 경계 계산 간격은 0.5m이다.
4. 동일 판정 내부는 기본 격자 결과를 재사용하고 세부 격자에 채운다. 전체 구역을 0.5m로 모두 재계산하는 것은 아니다.
5. 세밀한 마스크를 선형 보간으로 지형 위에 표시한다. 임의 둥글리기나 물리적 반그림자 모형은 사용하지 않는다.

기본 격자에서 전혀 포착하지 못한 아주 좁은 그늘은 누락될 수 있다. 0.5m는 경계 계산 간격이며 실제 정확도를 뜻하지 않는다. 약 30m급 DSM 유래 지면, 높이 추정/미상 건물, 단일 높이 프리즘, 수목 차폐 미반영 등의 한계는 남아 있다. 건물 모서리에서 실제로 생기는 각진 그늘은 유지한다.

## 검증

- 40개 테스트 파일, 225개 검사 통과. TypeScript/Vite 빌드 성공.
- 소수점 위치의 건물 모서리와 그림자 경계 사례에서 경계 세분화 결과를 전체 0.5m 계산 결과와 비교하여 일치 확인. 이는 해당 합성 기준 사례에 대한 검증이다.
- 큐의 중간 요청 생략, 최신 요청 실행, 장면 폐기 후 결과 무시, 오류 후 회복 검증.
- 슬라이더 변경 시 워커·이미지 소스 재사용, 기존 레이어 유지, 멈춘 후 정밀화, 레이어 해제 시 정리 검증.
- 브라우저: 여의도·동지에서 12:30 → 13:00 → 13:30 → 14:00을 빠르게 입력. 이전 시각의 결과 유지 안내와 최종 14:00 기본 2m/경계 0.5m 완료 상태 확인.
