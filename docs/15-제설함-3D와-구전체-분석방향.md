# 제설함 3D·10분 재생과 구 전체 그늘 분석 방향

2026-09-21 후속 요청.

## 제설함 3D

기존 deck.gl 공유 오버레이에 몸체, 뚜껑, 받침/손잡이, 표식의 네 가지 저면수 메시를 인스턴싱한다. 주황색 함과 청색 뚜껑, 흰색 눈 표식을 사용한다. 외부 3D 모델·텍스처 다운로드나 새 렌더러를 추가하지 않았다.

줌 15.5 이상에서 화면 범위에 있는 최대 800개만 3D로 표시한다. 크기는 확대된 위치 기호로 조절하며 실제 치수·방향·제품 외형을 복원한 것은 아니다. 지면 고도를 읽을 수 없거나 멀리 떨어진 축척에서는 기존 2D 위치 점을 유지한다. 구/검색 필터와 제설함 토글을 공유한다. 실제 3D로 표시하는 ID는 2D 점에서 제외해 이중 표시를 막는다. 3D 모델을 눌러도 원본 속성을 조회할 수 있고, 목록 선택은 줌 18·기울기 55도로 이동한다. 모형은 차폐 계산에 넣지 않는다.

## 시간 자동재생

슬라이더 옆 재생/일시정지 버튼을 제공한다. 화면 시간은 1.5초 간격 타이머로 10분씩 증가한다. 그늘 프레임 계산이 진행 중이면 다음 증가를 기다려 요청 시각만 앞서가는 것을 막는다. 수동 슬라이더 조작, 날짜·분석영역 변경, 탭 숨김에서 정지하고 언마운트 시 타이머를 해제한다. 23:59를 넘기지 않으며 마지막에 정지한다. 이후 ‘다시 재생’은 같은 날짜 00:00부터 시작한다. 하루 일조 결과 표시 중 재생을 누르면 선택 시각의 그늘 표시로 전환한다.

화면에 요청한 시각과 실제 계산된 그늘 시각은 기존 상태 문구로 구분한다. 정상 계산에서는 현재 프레임의 정밀 보정이 끝난 뒤 다음 시각으로 진행한다. 계산 오류나 데이터 부족은 상태 문구로 알리며 영상 인코딩 기능은 아니다.

## 구 전체 그늘 분석

현재 하루 일조는 4m 격자·10분 간격으로 브라우저 워커에서 광선 차폐를 반복한다. 선택 시각 그늘은 기본 2m/경계 0.5m 보정이며 큰 범위는 40만 기본 셀 상한에 맞춰 간격을 늘린다. 직접 선택 최대 크기는 1.5km, 빠른 선택은 250m/500m/1km다.

공개 구 경계 SHP를 원래 평면좌표계로 면적 계산한 추정 비교(버퍼·외접 사각형·건물 밀도 제외):

| 범위 | 면적 | 4m 격자 수 | 500m 사각형 대비 |
|---|---:|---:|---:|
| 500m 사각형 | 0.25㎢ | 15,625 | 1배 |
| 1km 사각형 | 1㎢ | 62,500 | 4배 |
| 마포구 | 약 23.86㎢ | 약 149만 | 약 95배 |
| 서초구 | 약 46.92㎢ | 약 293만 | 약 188배 |

이 수치는 격자 수 비교이며 실행시간 배수나 실측 벤치마크가 아니다. 현재 구현의 외접 사각형·주변 버퍼와 건물 수를 고려하면 단순 면적보다 계산 범위가 늘어난다.

담당자용 기본 흐름은 구 전체를 보는 것이 적절하다. 권장 후속 구조는 구 전체 10~20m 개요 사전 계산, 도로·보도 중심 2~5m 후보구간 분석, 선택 지점 정밀 검토다. 10~20m는 개요용 제안이며 좁은 도로의 결빙 판정 정밀도를 보장하지 않는다. 결과를 날짜·시간대별 타일로 저장해 지도는 필요한 타일만 읽고, 관측/예보는 별도 주기로 갱신한다. 날짜별 반복 계산의 범위와 겨울철 시간 간격은 성능·현장 검증으로 정한다.

이번 변경은 3D 제설함 표시를 구현한다. 구 전체 그늘 사전 계산이나 서버 작업 큐를 구현한 것은 아니다. 추가 상시 서버·유료 서비스를 생성하지 않았다.

## 검증

자동검사 254개 통과. 메시의 유한 좌표·법선, 화면 범위·확대 수준·800개 제한, 고도 기준 배치, 재생 간격과 정지/재시작/타이머 해제를 확인했다. 실제 지도에서 제설함 확대 표시와 선택을 확인하고 클로드 읽기 전용 리뷰의 이중 표시·가려진 모형 선택 문제를 반영했다.
