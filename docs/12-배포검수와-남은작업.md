# 배포 검수와 남은 작업

## 공개 서비스 전에 해결할 항목

`npm audit`에는 mesh-layers → glTF/texture-compressor → image-size 계열의 **high 알림 6개(전이 의존성 포함)**가 남는다. 알림 6개는 독립 취약점 6개를 의미하지 않는다. 현재 나무는 코드 메시로 생성하며 외부 glTF/ICNS/JXL/HEIF 업로드 기능은 없지만, 이를 근거로 의존성 문제가 해결됐다고 표시하지 않는다. 자동 수정 제안은 다른 deck.gl 패키지와 맞지 않는 8.x 다운그레이드이므로 강제 적용하지 않았다. 패키지 업스트림 수정 또는 해당 의존 경로 제거를 추적해야 한다.

또한 다음 항목은 이번 GitHub 설정에서 완료했다고 주장하지 않는다.

- Vercel 라이브 사이트 생성과 비공개 저장소 팀 배포 요금제/권한 확정.
- 서울 전체 데이터의 서비스용 저장소/CDN 또는 빌드 다운로드 연결.
- 정밀 지면·건물 원천 확보와 현장 그늘 검증.
- 수목 차폐·기상·위험도 모델.

현재 단계는 비공개 팀 협업용 프로토타입과 재현 가능한 시연 빌드다. 미해결 사항은 저장소 Issues에서 계속 관리한다.

## 팀원이 받는 자료로 실행하는 검사

Git에 포함한 파일만 별도 폴더에 내보내서 설치·테스트·빌드·데이터 검사를 수행한다. 덕양구 CCTV 원천 결과물은 서울 저장소에 배포하지 않으므로 해당 결과물에만 의존하는 레거시 회귀검사 19개는 파일이 없을 때 명시적으로 건너뛴다. 파일이 있는 기존 개발 PC에서는 계속 실행된다. 서울 기능 및 나머지 독립 검사는 그대로 실행하며 누락된 서울 데이터를 성공으로 간주하지 않는다.

초기 팀 체크아웃 검사: 208개 통과, 레거시 데이터 검사 19개 건너뜀, 0개 실패. 시연 자료는 건물 28,323개/25타일, 수목 24,115개/24타일, 지면 816×416셀, 제설기지 86개이며 원본 전체 자료와 구분한다. GitHub Actions의 Linux/Node22 실행도 성공했다. `main` 강제 보호는 GitHub의 Pro 요구 응답으로 비활성 상태를 유지한다.
