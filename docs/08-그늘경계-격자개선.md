# 그늘 경계 격자 개선

2026-09-18 · 여의도 화면에서 그늘이 큰 계단·각진 블록처럼 보인다는 사용자 피드백.

확인한 원인: 선택 시각 그늘은 8m 셀의 중심에서 이진 차폐를 판정하고 `raster-resampling: nearest`로 표시했다. 이 조합에서 대각 경계도 8m 계단으로 확대된다. 건물을 단일 높이 프리즘으로 단순화하는 모델 한계도 남아 있다.

수정:

- 기본 광선 계산 간격을 8m에서 2m로 축소. 일반 500m 관심구역 + 주변 300m는 2m 격자를 사용한다.
- 큰 관심구역에서는 40만 셀 이내가 되도록 0.5m 단위로 간격을 늘리고 실제 간격을 화면에 표시한다.
- 인접 계산 샘플 사이에 선형 보간을 사용해 경계의 화면 계단을 완화한다. 물리적 반그림자/태양 원반 모델을 추가한 것은 아니다.
- 하루 누적 일조시간의 4m·10분 계산은 변경하지 않는다.

검증:

- 자동검사 38개 파일, 220개 통과. TypeScript/Vite 빌드 성공.
- 평지, 높이 20m 프리즘, 태양고도 45°의 합성 기준 사례에서 투영 길이 20m와 2m 격자 판정의 일치 확인.
- 브라우저에서 여의도 프리셋, 동지 정오 계산을 실행하여 2m 격자 상태와 세밀해진 그림자 경계 확인.
- 기록: `reference/seoul-map-acceptance/tests-shadow-resolution.log`, `build-shadow-resolution.log`.

이 검증은 실제 현장 정확도를 입증하지 않는다. 2m는 광선 계산 간격이며 실제 고도 정확도가 아니다. 원천 고도는 약 30m급 DSM에서 가공한 추정 지면이고 대형 건물/수목 잔류가 가능하다. 지붕·층별 단차와 수목 차폐는 계산하지 않으며, 높이 미상 건물은 제외한다. 각진 건물의 실제 그림자에도 직선·모서리가 존재하므로 모든 경계를 둥글게 처리하지 않는다.
