# 자치구·제설함과 영역 전환

2026-09-21 사용자 요청: 담당자가 구 단위로 판단할 수 있도록 구 표시 토글·선택 기능, 제설함 CSV 반영, 영역 변경 잔상 개선.

## 동작

서울 전체 개요에서 25개 구 이름과 경계를 표시한다. 담당 자치구 선택 또는 지도 라벨을 누르면 해당 구를 강조하고 전체가 보이도록 이동한다. 구 경계 토글은 경계/이름만 숨기며 담당 구와 제설함 필터는 유지한다. 제설함은 주황색 시설 지점이다. 제설기지는 기존 서울 전체 참고 레이어를 유지한다.

구별 제설함 수는 좌표의 공간 포함관계로 집계하며 관리기관명과 구별한다. 검색은 번호·기관·위치에 적용하고 구 전환 때 초기화한다. 10,435개 중 10개는 25개 구 폴리곤 중 하나에 명확히 들어가지 않아 전체 보기에서만 미분류로 보인다. 예를 들어 서초구 위치 분류는 505개로 원본 관리기관명이 서초구인 행 수와 다르다. 같은 좌표나 유사 번호도 원본 행을 유지한다.

위험자료를 불러온 경우 선택 구 폴리곤 내부 지점만 표시·집계한다. 경계가 없으면 숫자를 0으로 단정하지 않고 집계 대기로 표시한다. 외곽 경계선에 정확히 놓인 위험점은 인접 구 양쪽에 포함될 수 있다. 이는 구 합계의 단순 합산을 위한 배타적 분류가 아니다.

구 전체는 담당구역·시설·위험자료 개요다. 기존 정밀 그늘 계산은 선택 지점 주변 250m/500m/1km로 유지하며 구 전체 계산 완료라고 표시하지 않는다. 정밀 분석 중 빈 지도 클릭으로 다른 구 전체로 자동 전환하지 않는다.

## 출처와 좌표

서울특별시 OA-22161 공식 ZIP을 직접 내려받았다. SHP의 PRJ와 안내는 EPSG:5181이다. 파일 수정일 2023-10-31과 카탈로그 갱신일 2026-09-11은 별개이며 최신 법적 경계로 단정하지 않는다.

사용자가 준 ‘서울시 제설함 위치정보.csv’는 CP949, 10,435행, x좌표값/y좌표값/제설함번호/관리기관명/위치상세정보 열이다. 기존 제설전진기지와 동일 계열의 좌표값을 1,000으로 나누고 EPSG:5186으로 해석했다. 모든 행이 서울 주변 범위검사를 통과했다. 단위·EPSG는 추론 상태로 표시하며 현장 정확도, 운영 상태, 재고를 검증한 것은 아니다. 원본 자료 기준일은 미상이다.

변환 스크립트는 `tools/prepare_district_snow_boxes.py`. 원본은 source-data 아래 보존하고 공개 지도용 결과·출처 메타데이터만 app/public/overlays에 둔다. 기존 대용량 Release ZIP과 분리해 빌드에서 누락·덮어쓰기되지 않게 한다. 각 원본 SHA256, 출처 URL, 변환 방법, 원본/표시/미분류 건수는 meta.json에 기록한다. 두 데이터 모두 공공누리 1유형으로 출처를 표시한다.

## 잔상 수정

구·AOI 전환 시 건물/수목 배열, 선택 정보, 일조 결과를 즉시 비우고 로딩 순번과 장면 revision을 증가시킨다. 같은 구 전체보기를 반복해도 새 장면을 로드한다. 중단된 이전 fetch는 응답을 적용하지 않는다. 오래된 지도 idle 콜백은 effect 정리에서 해제한다. 이미지 레이어 cleanup은 다음 화면 그리기 전에 수행한다.

같은 구역에서 시간만 바꾸는 경우에는 기존 슬라이더 연속성을 유지한다. 구역이 달라지면 워커를 종료하고 새 장면을 만들며 이전 워커 결과를 버린다. Claude의 읽기 전용 검토를 두 차례 반영했다. 워커 재사용 확대 등 이번 잔상 수정에 필요하지 않은 변경은 하지 않았다.

## 검증

44개 테스트 파일·247개 항목과 프로덕션 빌드 통과. 모든 제설함 분류를 배포할 경계 폴리곤으로 다시 대조하고 일치 확인. 25개 구 라벨의 경계 내 위치, 제설함 전체 행 수·미분류 수, 검색과 구 필터, 이전 로딩 순번/늦은 이미지의 폐기를 검증했다. 브라우저에서 구 선택·토글·제설함 검색·상세·정밀 계산·다른 구 전환과 모바일 배치를 확인했다. 서초구 일조 완료 후 마포구로 전환했을 때 이전 분석 결과가 제거되고 마포구 제설함 582개로 바뀌는 것을 확인했다.
