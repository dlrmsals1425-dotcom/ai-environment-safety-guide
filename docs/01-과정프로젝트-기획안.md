## 1. 한 줄 요약

지형·건물·수목에 의한 차폐와 태양 위치, 기상 조건을 하나의 계산 체계로 묶어 **"이 골목은 오늘 몇 시에 어떤 환경 위험이 커지는가"** 를 시간대별로 설명하고, 도보 이동과 현장 점검 판단을 돕는 교육용 프로젝트다.

## 2. 배경과 문제 정의

현장에서 환경 위험은 지점이 아니라 **시간의 함수**로 나타난다. 같은 골목이라도 정오의 무차폐 구간은 일사 노출이 크고, 겨울 오후 내내 그늘인 구간은 **노면 건조가 늦어질 수 있다**. 그러나 현재 접근 가능한 정보는 다음과 같이 분절되어 있다.

- 기상 정보는 **관측소 지점 값 또는 예보 격자 단위**로 제공된다. 폭 4~8m 골목의 실제 노면 상태와 동일하지 않다.
- 건물 형상 자료는 있으나 **지형 고저와 수목 차폐가 빠져** 있어 그늘 계산이 실제와 어긋난다.
- 시간대별 변화를 지도 위에서 함께 보는 수단이 없어, 점검 시간대 선정이 경험에 의존한다.

이 프로젝트는 위 간극을 메우는 **계산 절차와 표현 방법**을 설계하고, 그 한계를 정직하게 표기하는 방법까지 함께 다루는 것을 학습 과제로 삼는다.

## 3. 목적

1. 물리 기반 차폐·일사 계산과 기상 자료를 결합해 **시간대별 환경위험 지표**를 산출하는 절차를 수립한다.
2. 산출물을 **이동 안내(언제 어느 구간을 피하거나 택할지)** 와 **현장 점검 우선순위(언제 어디를 먼저 볼지)** 로 번역한다.
3. 각 결과에 **자료 품질과 미확보 자료를 함께 표기**하는 규칙을 만들어, 과신을 구조적으로 막는다.
4. AI/ML을 **물리·규칙 기반 baseline과 분리해 평가**하는 검증 설계를 수행하고, 그 과정을 교육 산출물로 남긴다.

## 4. 대상 위험 유형 (잠정 2종)

현 단계에서 다루는 위험 유형은 아래 2종으로 **잠정** 설정한다. 자료 확보 상황에 따라 축소될 수 있다.

### 4.1 하계 폭염·일사 노출

- 내용: 차폐가 없는 구간에서 체류·보행 시 누적되는 직달 일사 노출과 고온 부담.
- 산출 형태: 시간대별 **상대 노출 정도(등급)**. 절대 열지수·온열질환 위험도를 진단하지 않는다.
- 주요 입력: 태양 고도·방위, 건물·지형·수목 차폐, 기온·일사 관련 기상값.

### 4.2 동절기 그늘 지속 + 기온·강수 조건에 따른 결빙 **가능성**

- 내용: 일조가 장시간 닿지 않는 구간에서, 기온·강수(강설) 조건이 겹칠 때 **노면 건조가 늦어질 수 있고** 재결빙 **가능성**이 상대적으로 높아지는 상황.
- 산출 형태: **가능성 등급(참고값)**. "결빙 있음/없음"을 판정하지 않는다.
- 주요 입력: 일조 시간 누적, 최근 기온 이력, 강수·강설 이력, 차폐 구조.
- 유의: 기온 0℃ 이하만으로 결빙을 단정하지 않는다. 노면 수분·노면 온도·배수·제설 등 **누락 요인을 함께 표기**한다.

### 4.3 해석 원칙 (필수 준수)

| 원칙 | 내용 |
|---|---|
| 그늘의 양면성 | **그늘 자체는 위험이 아니다.** 여름에는 보호 요소, 겨울에는 결빙 가능성 요소로 **계절과 조건에 따라 반대 방향**으로 해석한다. 단일 "그늘 = 위험" 규칙을 만들지 않는다. |
| 확정 금지 | 결빙·사고 발생을 확정하거나 예측한다고 표현하지 않는다. 산출물은 **조건적 가능성**이다. |
| 범죄예측 아님 | 본 프로젝트는 **범죄 발생 예측이 아니다.** 대상은 환경·기상 요인이며, 개인 식별 정보나 사건 이력을 학습 대상으로 삼지 않는다. |
| 대표성 한계 명시 | 기상 관측소 값과 예보 격자는 **골목 실측이 아니다.** 모든 기상 기반 산출물에 이 한계를 함께 표기한다. |
| 미확보 표기 | 계산에 필요한 자료가 없는 영역은 비워두거나 "미확보"로 표시한다. 빈 곳을 추정값으로 메우고 침묵하지 않는다. |
| 품질은 서열이 아님 | 자료 품질은 단일 점수나 자동 우열로 표시하지 않는다. **4개 축(반영 요소 완전성·측정 품질·시점 적합성·공간 대표성)을 분리해 표기**한다(6.4항). |

## 5. 범위

### 5.1 1차 범위 (본 과정에서 달성 목표)

- 대상 지역: **서울특별시**. 서울 건물·수목 원천은 확보했고, 계산·시연을 먼저 수행할 **시범구역은 임의로 확정하지 않는다**(선정 기준은 04 문서 9항).
- 시간대별 차폐·일사 계산 체계 수립 및 검증.
- 위 4.1 / 4.2 두 지표의 **정의·산출·표기** 규칙 수립.
- 지도 기반 시간대별 조회와 품질 표기 화면(시연용).
- 검증 결과 보고서 및 한계 기술서.

### 5.2 2차 범위 (여건 충족 시)

- **노출 저감 참고 경로** 제시: 동일 출발·도착 구간에 대해 노출이 상대적으로 낮은 경로를 **참고용**으로 보여주는 기능. 보행 도로망·통행제약 자료(03 문서 R01) 확보가 전제다.

### 5.3 비범위 (하지 않는 것)

- **안전 경로 보장·인증을 하지 않는다.** 2차 범위의 경로 기능도 "참고"이며, 안전을 보장하는 표현을 쓰지 않는다.
- 결빙 발생 여부 판정, 사고 예측, 범죄 발생 예측.
- 개인 식별 정보, 신고·사건 이력의 학습·표시.
- 실시간 운영 서비스 배포 및 대외 공개.
- **기존 원본 프로젝트 `../cpted-sunmap`의 수정.** 원본은 보존하며 손대지 않는다(5.4항).

### 5.4 코드 베이스 취급 원칙

- `../cpted-sunmap`(빛길)은 **원본 보존 대상**이다. 본 프로젝트에서 수정·이동하지 않는다.
- 본 프로젝트의 `app/`은 원본에서 복사해 **현재 시점으로 동결한 출발점**이다. 과거 자산의 단순 참조본이 아니라, 여기서부터 시작한다.
- **후속 개발·수정은 `app/`에서만 진행한다.** 원본으로 변경을 되돌려 반영하지 않는다.
- 동결 시점의 내용·무결성 기록은 03 문서와 루트 README를 따른다.
- **신규 기반 지도는 Google Maps로 확정**되었다. `app/`의 MapLibre/deck.gl 구성은 레거시 출발점이며, 계산 로직 재사용 참고 대상일 뿐 신규 기반이 아니다.
- **코드 변경은 아직 하지 않는다.** 현재 단계는 자료 수집과 설계다.

> **수목 차폐 근사에 관하여**: LiDAR가 없더라도 **개별 수목의 위치·수고·수관폭 자료**(현재 확보분)로 수관을 단순 기하로 **근사한 차폐 계산이 가능하다.** 다만 수관 형상·가지 하단 높이·계절별 투과율이 근사값이므로 **정밀도와 검증 가능성에 한계**가 있다. 구간 단위 가로수 목록처럼 개별 좌표가 없는 자료만으로는 개별 그늘 계산을 할 수 없고, 자료 없는 나무를 실측 객체처럼 만들지 않는다.

**미확보 자료가 있는 한, 해당 요소를 반영했다고 표현하지 않는다.** 확보 여부는 단계 진입 조건([02 문서](02-설계와-단계별-검증.md) 게이트)으로 관리한다.

### 6.4 자료 품질 표시 원칙

품질을 단일 신뢰도 점수나 자동 서열(예: "정밀 자료가 항상 우월", "관측이 항상 예보보다 우월")로 표시하지 않는다. 아래 **4개 축을 분리해** 표기한다. 축별 정의와 운영 규칙은 02 문서 3.5항에 있다.

| 축 | 묻는 것 | 예 |
|---|---|---|
| 반영 요소 완전성 | 계산에 어떤 차폐 요소까지 넣었는가 | 건물만 / +지형 / +수목 |
| 측정 품질 | 값이 어떻게 얻어졌는가 | 대장 제공값 / 층수·용도 추정 / 관측 / 모델 산출 |
| 시점 적합성 | 조회 시각과 자료 시점이 맞는가 | 과거·현재는 관측, **미래 시각은 예보가 적합** |
| 공간 대표성 | 값이 대표하는 공간 범위는 어디인가 | 관측소 거리, 예보 격자 크기, 격자 해상도 |

- 요소를 더 많이 반영했다고 해서 결과가 더 정확하다는 보장은 없다. 수관 투과율·낙엽·높이 추정 오차 등 **검증되지 않은 요인이 남는다.**
- 보수적 운영을 위해 화면에는 **가장 취약한 축을 함께 노출**하되, 이는 **검증 전 임시 초안 규칙이며 확률적 신뢰도가 아니다.**

## 7. 활용 시나리오 (교육 시연 기준)

1. **이동 안내**: 특정 날짜·시간대를 선택하면 구간별 노출/가능성 등급이 지도에 표시되고, 각 등급의 근거(차폐 시간, 기상 조건, 품질 표시)를 함께 읽는다.
2. **현장 점검 우선순위**: 하루 중 어느 시간대에 어느 구간의 값이 높은지를 비교해, 점검 순서를 잡는 참고 자료로 쓴다.
3. **한계 설명**: 같은 화면에서 "이 구간은 수목 자료 미수록(예: 가로수 자료에 종로구 없음)으로 여름철 차폐가 과소 추정될 수 있음", "지형 미반영 구간으로 경사지 판정 보류", "배경 3D는 표현이며 분석 입력이 아님"과 같은 문구를 함께 보여준다.

시연은 **결론을 주장하는 방식이 아니라, 근거와 한계를 같이 보여주는 방식**으로 구성한다.

## 8. AI/ML 적용 방침

| 구분 | 방침 |
|---|---|
| 우선순위 | **물리 계산 → 규칙 기반 baseline → (조건 충족 시) ML** 순서로 진행한다. baseline 없이 ML을 먼저 만들지 않는다. |
| 성능 주장 | **학습 라벨과 시공간 분리 검증 체계를 확보하기 전에는 "AI 정확도" 수치를 주장하지 않는다.** 확보 전 산출물은 전부 "미검증 시제품"으로 표기한다. |
| 비교 기준 | ML 결과는 항상 물리·규칙 baseline과 **같은 검증 분할에서 비교**한 값으로만 보고한다. |
| LLM 역할 | LLM은 **근거 설명 보조**(산출된 수치와 한계를 문장으로 풀어 설명)에 한정한다. 위험도 값을 LLM이 생성하거나 보정하지 않는다. |
| 라벨 | 라벨 정의·수집 방법은 02 문서에서 별도 설계한다. 라벨 없이 학습을 시작하지 않는다. |

## 9. 단계 구성 개요

교육과정 기간이 아직 확인되지 않았으므로 **주차를 단정하지 않는다.** 아래는 순서와 진입 조건 중심의 단계 구분이며, 각 단계의 산출물·평가·시연 방법은 02 문서에서 상세히 정의한다.

| 단계 | 이름 | 핵심 질문 |
|---|---|---|
| S0 | 자료 정리·기준선 확인 | 무엇을 가지고 있고 무엇이 없는가 |
| S1 | 물리 차폐·일사 계산 확장 | 지형·수목을 넣으면 계산이 어떻게 달라지는가 |
| S2 | 기상 결합과 지표 정의 | 두 위험 유형을 어떤 입력으로 어떻게 등급화하는가 |
| S3 | 규칙 기반 baseline 확립 | ML 없이 어디까지 설명되는가 |
| S4 | 검증·라벨·(조건부) ML | 검증 가능한 형태로 만들었는가, 그 다음에야 학습할 가치가 있는가 |
| S5 | 시연·문서화 | 근거와 한계를 함께 전달할 수 있는가 |

- S4는 라벨과 시공간 분리 검증 확보가 전제다.
- **정밀 표고를 확보하지 못해도 S2는 진행한다.** 건물만 반영한 L0 차폐에 기상을 결합해 **제한된 기준선 시연**까지 갈 수 있다. 단 "지형 미반영"을 화면과 보고서에 명시하고, **구릉지·경사 구간은 판정 보류**로 처리한다. VWorld 90m DEM은 거친 참고용이며 골목 단위 계산에 쓰지 않는다.
- 기상 API를 확보하지 못한 경우에만 지표 산출이 정의 단계에 머문다.

## 10. 평가 관점 (요약)

- **정직성**: 미확보·저품질 구간이 결과 화면과 보고서에 실제로 표기되는가.
- **재현성**: 동일 입력에서 동일 산출이 나오고, 계산 과정이 문서로 추적되는가.
- **물리 타당성**: 기지의 기하 조건에서 그림자·일조 계산이 기대값과 일치하는가.
- **설명력**: 각 등급의 근거를 사람이 읽을 수 있는 문장으로 제시하는가.
- **절제**: 보장·확정·예측 표현을 쓰지 않는가.

세부 지표와 합격선은 02 문서의 게이트 항목을 따른다.

## 12. 용어

- **차폐(Occlusion)**: 태양과 지점 사이를 건물·지형·수목이 가려 직달광이 닿지 않는 상태.
- **일조 시간**: 대상 시간 구간 중 직달광이 닿은 시간의 합.
- **노출 등급**: 절대 물리량이 아닌, 대상 구역 내 **상대 비교** 등급.
- **결빙 가능성**: 결빙이 일어난다는 판정이 아니라, 조건이 겹칠 때 상대적으로 가능성이 높다는 참고 표시.
- **baseline**: 학습 없이 물리 계산과 명시적 규칙만으로 만든 기준 산출물.
- **동결 출발점(`app/`)**: 원본에서 복사해 시점을 고정한 코드·데이터. 이후 개발은 여기서만 진행한다.

## 13. 현 단계 결정 사항

- 코드 개발은 **아직 착수하지 않는다.** 본 문서와 02 문서의 설계 확정, 자료 목록 정리 완료 후 S0부터 시작한다.
- `../cpted-sunmap` 원본은 보존하고 수정하지 않는다. 후속 개발은 동결된 `app/`에서만 진행한다.
- 자료 목록·출처·한계는 [docs/03-데이터와-출처목록.md](03-데이터와-출처목록.md)를 정본으로 하며, 본 문서는 확인되지 않은 URL을 만들지 않는다.
