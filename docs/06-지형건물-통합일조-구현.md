# 서울 지형·건물 통합 일조 지도

2026-09-18 · 사용자 지시: MapLibre/OSM 방향 구현, 제설전진기지 추가, 표면고도와 건물 일조 통합.

## 현재 동작

- 실행 앱: `app/`, 개발 서버 `http://127.0.0.1:5174/`.
- 하나의 MapLibre 지도에 추정 지형, 3D 건물, 수목 위치, 제설전진기지 표시. 기존 두 모드 선택은 제거.
- 서울숲·남산·여의도 버튼으로 500m 관심구역 지정. 지도에서 사각형을 직접 지정할 수도 있음.
- 선택 시각 지면 그늘: 8m 격자, 별도 취소 가능한 워커. 날짜·시간·관심구역 변경 시 이전 결과 제거 후 재계산.
- 하루 일조 가능시간: 4m 격자, 10분 간격, 병렬 워커. 결과와 선택 시각 그늘을 겹치지 않게 표시.
- 결과는 MapLibre image/raster 레이어로 지형에 투영. 평면 그림자 수광판은 제거.
- OSM/배경 없음 전환은 지도 스타일 전체 교체 없이 동작. 분석 자료는 로컬 파일.

## 높이와 계산 기준

1. 원본 Copernicus DSM은 보존한다. `tools/prepare_seoul_ground.py`가 원본 1 arcsecond 격자에 3×3 최소 필터 후 최대 필터를 적용한 추정 지면을 만든다.
2. 같은 배열에서 로컬 RGB 고도 타일 162개와 Float32 고도 격자(7,587,181셀, 30,348,724바이트)를 생성한다. 경위도 격자는 북→남 행 순서이며 쌍선형 보간한다.
3. 건물 프리즘의 기초 높이는 외곽선 꼭짓점에서 읽은 추정 지면의 평균이다. 지도 좌표 Z와 분석 `baseZ`는 동일하다. 건물 높이는 대장값 또는 원천 층수 기반 추정 상대높이다.
4. 계산점은 추정 지면 + `z0`(기본 0m). `z0`는 절대표고가 아닌 지면 위 높이이다.
5. 태양 방향으로 지형은 15m 간격, 최대 3km를 검사한다. 건물은 실제 외곽·구멍을 보존한 프리즘에 공간 인덱스와 광선 교차를 적용한다. 건물 확보 범위는 AOI+300m이다.
6. 워커에는 AOI+3km 주변 지형만 잘라 전달한다. 주변 지형 부족, 건물 로드 오류, 타일 일부 누락, 기하 파싱 누락이면 계산을 막는다. 수목은 위치 표시만 한다.

제설기지 좌표는 원천 정수좌표를 1,000으로 나누고 EPSG:5186으로 해석했다. 서울 공개 API 표본 및 주소 2건과 교차 확인했지만, 공급자가 EPSG·배율을 명시 확인한 것은 아니다. `coordinateStatus=inferred-projection`을 보존한다. 시설 위치를 제설 능력·출동 범위·결빙 위험으로 환산하지 않는다.

## 해석상의 한계

- 3×3 opening은 정밀 DTM 추출이 아니다. 큰 건물·숲 높이의 잔류, 작은 능선 평활화, 경사면 기초 높이 오차가 가능하다. 지면 추정 실패율과 현장 오차는 미검증이다.
- 화면의 지형 메시는 고도 타일을 다시 보간하므로 원본 격자와 완전히 일치하는 측량 모델이 아니다. 0.1m RGB 인코딩 간격은 현장 정확도가 아니다.
- 4m/8m 계산 격자는 30m급 고도 원천을 정밀하게 만드는 것이 아니다.
- 결과는 지면의 기하학적 일조 가능시간이다. 옥상·벽면, 구름·기상, 수목 차폐, 복사에너지, 결빙, 위험도는 계산하지 않는다. 원천 DSM에 남은 수목 표면은 의도적인 수목 모델과 구별한다.
- 높이 미상 건물은 윤곽만 표시하고 계산에서 제외하며 건수를 알린다. 300m 밖 건물과 3km 밖 산의 긴 그림자는 포함하지 않는다.
- 원본 빛길 `../cpted-sunmap`과 5173 서버는 별도 보존한다.

## 검증과 재생성

```powershell
python tools/prepare_seoul_ground.py
python tools/verify_seoul_ground.py
Set-Location app
npm.cmd test -- --run
npm.cmd run build
```

`reference/seoul-map-acceptance/ground-data-check.json`은 고도 타일 경계 포함 837개 픽셀과 Float32 분석 격자의 보간값을 대조한다. 최대 차이 약 0.051m는 인코딩/부동소수점 차이이며 현장 오차가 아니다. 단위검사는 능선 차폐, 높은 태양에서 차폐 해제, 건물 차폐, 높이 기준 일괄 이동 불변성, 지형 범위 부족, WGS/ENU 표고 일치를 확인한다.

렌더 구조 참고: [deck.gl MapboxOverlay](https://deck.gl/docs/api-reference/mapbox/mapbox-overlay). 건물은 절대 Z를 제공하고 지면 그늘은 MapLibre 래스터로 처리한다. 이후 라이브러리 변경 시 지형 카메라와 깊이 버퍼 정합을 재검증한다.

최종 검수: 36개 테스트 파일, 212개 검사 통과 및 TypeScript/Vite 빌드 성공(exit 0). 남산 동지 08:30 지형·건물 지면 그늘과 하루 일조 결과를 브라우저에서 확인했다. 남산 500m 구역의 동지 계산은 이 PC에서 0.99초였으며 성능 보장값은 아니다. 새 검수 탭의 오류 로그는 0건이었다. 상세 기록: `reference/seoul-map-acceptance/integrated-ui-check.json`. 기존 대형 번들 경고는 남아 있다.
