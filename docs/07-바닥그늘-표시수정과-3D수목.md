# 바닥 그늘 표시 수정과 3D 수목

2026-09-18 사용자 피드백 반영.

## 바닥 그늘

문제: 하루 일조시간 레이어가 켜지면 선택 시각의 지면 그늘을 숨겼지만 그늘 체크박스는 켜진 채였다. 시간 슬라이더는 건물 면 조명만 갱신하고 지면 그늘은 계속 숨겨져, 건물 명암만 계산하는 것처럼 보였다.

수정:

- 선택 시각 그늘과 하루 일조시간의 체크 상태를 실제 표시와 일치시킨다.
- 일조 계산 완료 시 일조시간만 켜고, 시간 슬라이더 이동 시 선택 시각의 바닥 그늘로 전환한다.
- 계산한 하루 결과 배열은 보존하므로 일조시간을 다시 켜서 볼 수 있다.
- 현재 표시 종류와 자료/AOI 미준비로 그늘을 표시하지 못하는 이유를 안내한다.
- 건물은 AOI+300m까지 표시하면서 그늘은 AOI 안에만 그리던 범위 불일치도 수정했다. 선택 시각 그늘은 같은 AOI+300m까지 표시한다. 외곽 경계에서는 더 바깥 건물이 확보되지 않아 참고용이며 하루 일조시간 계산은 기존 AOI와 주변 건물 버퍼를 유지한다.

이는 표시 제어 수정이며 새로운 물리 차폐 모델을 추가한 것은 아니다. 기존 지형·건물 계산 엔진을 사용한다.

## 3D 나무

- 초록색 원 레이어는 숨기고 기존 건물과 같은 deck.gl 오버레이에 줄기·수관 메시를 인스턴스로 표시한다.
- 수고와 수관폭이 모두 유효하면 원천 높이와 폭으로 스케일링한다. 밑동은 동일한 추정 지면에 배치한다.
- 일반 수관은 둥근 입체, 소나무·잣나무 등 해당 수종명은 원뿔형 수관이다. 모양과 줄기 굵기는 시각화용 근사이며 개체 복원이 아니다.
- 높이 또는 수관폭이 없거나 범위를 벗어나면 실제 크기를 만들지 않고 황갈색 고정 화면 크기의 나무 기호로 표시한다.
- `3D 수목` 체크박스로 표시를 제어한다. 나무 메시를 클릭하면 원래 위치와 수종·수고·수관폭·원천 연도를 조회한다.
- 데이터는 2013 공개본이다. 계절별 낙엽, 가지·잎의 실제 구조, 개별 나무의 현재 상태는 반영하지 않는다. **수목에 의한 지면 그림자와 일조 차폐는 아직 계산하지 않는다.**

구현: `treeModels.ts`, `treeDeckLayers.ts`, `BuildingLayer.tsx`, `MapView.tsx`. 모델 메시와 미상 나무 SVG는 코드로 작성했으며 외부 3D 모델을 내려받지 않았다. 렌더러는 `@deck.gl/mesh-layers` 9.4.0을 추가했다.

검증: 37개 테스트 파일, 218개 검사 통과. TypeScript/Vite 프로덕션 빌드 통과. 원천 수고·폭 보존, 고도 배치, 결측값 기호 전환, 메시 정상값을 검사했다. 브라우저에서 서울숲 입체 가로수와 클릭 속성(양버즘나무, 수고 34m·수관폭 6m, 원천값)을 확인했다. 이 값의 표시는 원천 정확도를 검증했다는 뜻이 아니다.

브라우저 회귀 검증에서는 동지 하루 계산 후 그늘 체크가 꺼지고 일조시간 체크가 켜지는 것, 시간을 14:00으로 옮기면 반대로 전환하고 그늘을 다시 계산하는 것을 확인했다. 최종 화면에 주변 300m를 포함한 지면 그늘과 3D 나무를 함께 표시했다. 관심구역 미지정 시에는 ‘500m 사각형’ 또는 지역 프리셋으로 구역을 지정하라는 대기 사유를 표시한다.
