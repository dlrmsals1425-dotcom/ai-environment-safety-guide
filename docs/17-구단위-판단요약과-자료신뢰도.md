# 구 단위 판단 요약과 태양·그늘 자료의 해석

2026-09-23 후속 요청: 선택한 구 전체가 보이고 그 구에 대한 정보가 먼저 나오도록 복잡한 시연 화면을 단순화한다. 태양빛 계산을 의사결정에서 어떻게 다룰지도 구분한다.

## 화면 흐름

시연 모드 상단의 담당 자치구 선택 → 구 전체 지도와 해당 구 판단 요약을 동시에 표시한다. 다른 탭을 보고 있어도 구를 바꾸면 요약 탭과 패널 상단으로 복귀한다. 서울 전체에서는 25개 구 목록을 표시하고 구 선택을 유도한다.

요약은 현재 판단(가상), 이유 한 문장, 제설 검토/결빙 확인 필요/경과 관찰의 배타적 건수, 기온/적설/구름 가정, 주요 장소 3곳으로 구성한다. 대상은 기존 구별 가상 장소 6곳이다. 구 전체 지도 시점과 구 전체를 실제 분석했다는 주장을 구분하며 제목·집계·지도에 가상 표시를 유지한다.

장소 선택은 상세정보만 열고 지도를 자동 확대하지 않는다. ‘이 장소 확대’를 따로 누르면 확대하고 ‘구 전체 보기’로 돌아오면 장소 상세를 닫는다. 지도에서 장소를 눌렀을 때도 판단 요약 탭으로 복귀한다. 날씨 가정·작업계획·점수·자료 설명은 펼침 메뉴로 유지한다.

좌측 지도 설정은 지도·시설 설정 서랍으로 옮겼으며 자료 오류가 있으면 닫힌 제목에도 확인 필요를 표시한다. 250m/500m/1km 선택은 상단 ‘지점별 그늘 도구’ 아래로 옮겨 구 선택과 구분한다. 정밀 범위가 활성화되면 해당 도구를 펼친다.

## 태양과 그늘 자료의 판단

계산값과 관측값이라는 구분만으로 정확도를 결정할 수 없다. 태양의 방향/고도는 날짜·시간·좌표를 이용한 천문 계산량이다. 현재 사용 중인 SunCalc 구현의 현장 오차나 독립 정밀 천문 모델과의 정량 비교 결과는 제시하지 않는다.

그늘·일조 가능시간은 태양 위치 외에 건물 기하·높이, 지면 표고, 차폐 계산 간격에 의존하는 모델 산출물이다. 약 30m급 DSM에서 가공한 추정 지면, 일부 층수 기반 높이, 단일 높이 건물, 수목·구름 차폐 미반영 등의 한계가 있다. 0.5m는 경계 계산 간격으로 현장 정확도가 아니다. 실제 도로 일사량/노면온도와 동등하게 취급하지 않는다.

기상청 관측은 관측 지점과 시각의 측정값이며 위치 대표성·품질정보가 필요하다. 예보는 예측자료다. 공개 건물자료도 갱신일·누락·높이 출처를 확인해야 한다. 공개 여부가 무오차를 보증하지 않는다.

현재 서비스에서는 추정 그늘을 ‘햇빛이 적을 수 있는 장소를 살펴보는 보조자료’로 사용한다. 실제 제설 판단은 노면온도·습윤/잔설·현장 확인·기상 관측/예보·제설 이력과 결합하고, 날짜/장소별 검증 후 활용 범위를 정해야 한다. 그늘만으로 결빙 확정이나 제설 불필요를 판정하지 않는다. 가상 모드 점수는 별도의 시연 규칙이며 건물 그늘 계산과 직접 연결되지 않았다.

화면에는 ‘태양 위치(천문 계산)’, ‘추정 그늘’, ‘일조 가능시간 추정’, ‘실측 일사량 아님·현장 미검증’을 표시한다. 태양 상태의 위치 기준은 선택 AOI, 선택 구 기준점, 서울 초기 기준점 순서다.

참고: https://gml.noaa.gov/grad/solcalc/calcdetails.html (NOAA도 계산과 실제 관측 사이의 대기/환경 차이를 설명한다. NOAA의 정확도 수치를 현재 앱의 정확도로 전용하지 않는다.)

## 검증

48개 파일·266개 자동검사와 프로덕션 빌드 통과. 배타적 집계/빈 자료 보류, 상위3곳→6곳 확장, 장소 선택 시 카메라 이동 없음, 다른 탭에서 구를 바꾸거나 같은 장소를 다시 선택해도 요약 탭 복귀를 검사했다. Chrome에서 서초구 선택 시 전체 경계와 서초구 요약 동시 표시, 장소 상세 선택 후 전체 시점 유지, 구 전체 복귀 시 상세 해제, 서울시 구 선택 목록, 모바일 첫 진입과 상단 선택 도구 배치를 확인했다. 클로드 읽기 전용 리뷰를 반영했다.
