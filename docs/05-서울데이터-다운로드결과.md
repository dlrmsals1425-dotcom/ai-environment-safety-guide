# 서울 데이터 다운로드 결과와 품질 확인

확인일: 2026-09-18. 대상 지역 **서울특별시**, 신규 지도 기반 **Google Maps**.
이번 작업은 실제 원본 수집과 검사, 터미널 경로 전환, 설계 갱신이다. 신규 서울 지도나 위험도 기능을 구현한 것은 아니다.

## 2. 품질 검사에서 확인된 사항

### 건물

- 높이 A16에 양수가 있는 레코드: **305,753개(43.9456%)**.
- 0·음수: **389,781개**, 결측/해석 불가: **220개**.
- 양수라도 정확성이 검증된 값은 아니다. 최댓값 **11,700m** 등 검토가 필요한 이상치가 있다.
- 300m 초과는5개. 서울의 실제 초고층이 포함될 수 있으므로 이전 덕양구 코드의 300m 상한을 그대로 적용하지 않는다.
- 지상층수 양수는545,204개. 높이 추정에 사용한다면 추정값임을 표시하고 원본 높이를 덮어쓰지 않는다.
- 695,754는 원본 형상 레코드 수다. 중복·부속건물 등 추가 정리 전 숫자이며 독립 건축물 수로 단정하지 않는다.

### 수목

- 원본 ZIP에 `.shp/.shx/.dbf/.prj`가 포함된다. `.prj`는 WGS84 지리좌표이고 실제 DBF는 **CP949**로 읽힌다. 카탈로그의 UTF-8 안내와 달라 인코딩 기록을 별도로 남겼다.
- 가로수는24개 구이며 **종로구가 빠져 있다는 제공처 안내**가 있다. 공원·사유지 수목은25개 구 레코드가 있다.
- 수고 양수: 가로수253,646개 / 공원·사유지178,323개 / 보호수309개.
- 수관너비 양수: 가로수253,065개 / 공원·사유지177,687개 / 보호수289개.
- 높이·수관 이상치와 결측이 있다. 양수 유무는 모델 사용 가능 판정이 아니다. 수목 단위는 추가 자료와 대조 후 확정한다.
- 가로수49개 점은 126~128°E, 37~38°N의 넓은 서울 주변 범위조차 벗어난다. 원본은 보존하고 후속 가공 시 검토 대상으로 분리한다.
- 공간파일은2013년 공개본이다. 카탈로그 갱신일2022-10-14, 메타수정일2026-04-07을 현장 조사일로 해석하면 안 된다.
- 수관하단 높이·계절별 투과율은 아직 확보하지 않았다. 사유지 수목 원본에 포함될 수 있는 소유자·관리자 항목은 그늘 분석에 필요하지 않으므로 앱용 파생자료에서는 제외한다.

### 표고/표면고도

- 국토지리정보원90m 자료는 넓은 지형을 비교하는 용도다. 골목·가로수 단위 그늘이나 결빙 가능성 계산의 정밀 입력으로 쓰지 않는다. 카탈로그에 **CC BY-NC-ND**가 표시돼 있어 원본만 보관했고 변형·배포 조건 확인 전 서비스 산출물로 가공하지 않는다.
- Copernicus GLO-30은 명칭에 DEM이 있지만 실제로는 **건물·식생을 포함하는 DSM**이다. 서울시가 만든1m 자료가 아니며 지면고도 DTM도 아니다.
- 두 Copernicus 타일은 서울 주변까지 포함하는1도 격자다. 30m급은 명목 해상도이며 실제 격자는1각초다. TIFF의3600×3600, WGS84, 픽셀 간격을 확인했다.
- 표면고도에 별도 건물·나무 높이를 다시 더하면 중복 가산될 수 있다. 원본 확보만으로 정밀 지형 차폐 계산이 완성된 것은 아니다.
- Copernicus 출처 표시 및 변형물 표시는 함께 받은 `eula_F.pdf`와 [공식 데이터 설명](https://dataspace.copernicus.eu/explore-data/data-collections/copernicus-contributing-missions/collections-description/COP-DEM)을 따른다.

## 3. 아직 내려받지 못한 정밀 자료

서울시2026 개방목록에서 **서울 전역 DEM1m, DSM1m, 약20점/㎡ 항공LiDAR, 정밀 건물높이 공간정보는 공개제한**으로 확인했다.
같은 목록의 **도로지역 DEM1m·DSM1m·LiDAR는 공개**로 표시되지만, 게시된 FAQ는 데이터 사용 신청·담당부서 문의 절차를 안내하며 직접 원본 다운로드 링크는 확인되지 않았다.
따라서 이 자료들은 **목록 및 절차 확인, 원본 미확보** 상태로 기록한다. 공개로 분류됐다는 이유로 원본을 받은 것처럼 표시하지 않는다.

S-Map 학술연구 안내는 신청서, 보안계획·서약 등 부대서류, 기관장 날인 연구계획 등 학술연구 증빙의 검토를 안내한다.
교육과정 개인 프로젝트가 해당 경로에 해당하는지와 도로지역 공개분의 간소한 제공 방식은 담당기관 확인이 필요하다.
요청서 원본을 `access-guides/`에 받아 두었으며 **기관에 연락하거나 신청서를 제출하지 않았다.**

## 4. 지도에 반영할 구조

```text
Google Maps: 지도 표현·지형/3D 표시 가능 범위 확인
                         ↑ 분석 결과 레이어
서울 공식 건물 + 수목 + 확보한 표고 + 기상 시계열
                         ↓
지형·건물·수목 차폐 계산 → 시간대별 환경위험 참고 지표
```

구글 지도 콘텐츠를 추출해서 자체 분석 자료로 저장하지 않는다. 분석은 별도 확보한 원본 자료에서 수행한다.
Google의 서울3D커버리지와 표시 수준은 API 연동 전에 보장하지 않는다. Google API키·구체 렌더방식·필요 시 Map ID 설정은 아직 준비하지 않았다.
자세한 구현방안은 [04 문서](04-서울시-고도지도-구현방안.md)를 따른다.

## 5. 터미널 전환

- Herdr 작업공간 표시명: **서울 환경위험 안내**.
- Claude(`claude-seoul`)와 Grok(`grok-seoul`)을 **새 프로젝트 루트에서 재시작**하고 실제 프로세스 cwd를 확인했다.
- Claude 대화는 기존 세션을 이어서 유지했다. Grok은 사용량0이므로 작업 경로만 설정하고 분석 작업을 배정하지 않았다.
- 실행 중인 Codex 호스트 세션의 시작 cwd는 기존폴더로 남아 있으나, 이번 명령의 `workdir`는 새 프로젝트 루트로 명시했다. 표시명 변경을 프로세스 cwd 변경으로 보고하지 않는다.
- 사용자가 별도로 실행 요청한 원본 빛길 서버는 유지했다. 새 프로젝트 서버나 Google Maps 앱은 실행하지 않았다.
- 기록: [터미널 설정 확인](../reference/terminal-setup-20260918.json).
