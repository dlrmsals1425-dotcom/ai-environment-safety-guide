# 가상 제설 의사결정 시연

2026-09-23 사용자 요청으로 가상 구름·태양·기상·제설 정보를 조절하며 제설 필요지역과 위험 후보를 검토하는 기능을 구현했다. 이 문서의 점수·지역 속성은 검증되지 않은 시연 규칙이다.

## 화면과 입력

기본 진입은 마포구의 2026-12-21 08:00 가상 겨울 아침이다. 기존 담당 구가 있으면 해당 구를 사용한다. 상단 가상 배너와 지도 워터마크를 항상 유지한다. 시연 진입 전 날짜·시각·담당 구·AOI·참고 시설/3D 표시 상태를 저장하고 종료할 때 복원한다. 기존 외부 위험파일은 수정하지 않으며 시연 중 그 레이어를 숨긴다.

강설 아침, 맑은 오후, 재결빙 밤 프리셋과 가상 기온(-15~10℃), 구름량(0~100%), 일사 강도(0~100%), 적설(0~15cm), 습윤도(0~100%) 조절을 제공한다. 실제 선택 날짜·시간의 태양고도를 SunCalc로 계산하지만, 기상 및 구역별 그늘 노출은 가정이다. 기존 건물/지형 그늘 분석 결과를 지수에 연결하지 않았다. 시간 재생은 시연 점수의 햇빛 항목에도 반영되며 야간은 일사 기여가 0이다.

## 가상 공간

공개 25개 자치구 경계 안에 각 6개씩 총 150개의 약 180m 정사각형을 생성한다. 네 모서리와 시작/끝 좌표가 구 내부임을 검사한다. 실제 도로, 제설 필요 면적, 침수·결빙 경계가 아니다. 도로망과 결합하지 않았으므로 실제 공원·산지·수면 위에도 위치할 수 있다. 이름은 ‘OO구 가상 구역 A~F’이고 경사·보행 수요·그늘 노출·눈 쌓임 배율은 모든 구에 공통인 6개 시연 프로필이다.

구별 생성 결과는 경계 객체에 캐시한다. 서울 전체 화면은 150개 면을 표시하고 목록/라벨은 상위 12개를 보여준다. 구를 고르면 해당 구의 6개를 모두 표시한다. 지도 GeoJSON에는 purpose: synthetic-demo를 지정한다.

## 예시 점수

위험 시연점수 = 저온×습윤(최대30) + 잔설(최대35) + 그늘×습윤(최대12) + 경사(최대10) − 낮의 햇빛 기여(최대12). 결과는 0~100으로 제한한다. 물리모델·확률·공인 결빙등급이 아니다. 건조하고 눈도 없을 때 저온만으로 위험 점수를 올리지 않는다.

우선순위 = 위험 시연점수×0.8 + 통행수요 가정×0.15 + 미처리 가산7(위험 점수가 있을 때). 우선순위60 이상·잔설1cm 이상은 ‘제설 우선 검토’, 나머지 위험점수30 이상은 ‘결빙 우려 확인’, 그 외는 ‘모니터링’으로 표시한다. 위험 후보 집계는 위험점수50 이상이며 제설 우선 집계와 겹칠 수 있다. 임계값 모두 시연용이다.

미처리/작업 중/처리 완료 가정은 잔설 배율을 1/0.65/0.25로 바꾼다. 완료를 안전으로 처리하지 않는다. 구름의 야간 복사 효과, 노면 열수지, 제설제 종류·농도, 재강설 및 실제 작업 이력은 계산하지 않는다.

## 가상 작업계획

담당자가 근거를 확인하고 1~6곳의 작업 한도 안에서 대상 구역을 담는다. ‘상위 N곳으로 계획 교체’는 현재 모니터링을 제외한 상위 후보로 선택을 교체한다. 한도를 줄이면 현재 우선순위가 높은 선택부터 유지한다. 조건을 바꾸면 선택 구역은 유지하고 점수와 권고를 현재 조건으로 재평가한다. 구를 바꾸면 계획을 비운다. 실제 배차·최적 동선·작업 명령은 아니며 서버 전송/영구 저장 없이 브라우저 메모리에서만 동작한다.
