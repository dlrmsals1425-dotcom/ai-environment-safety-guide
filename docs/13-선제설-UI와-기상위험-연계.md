# 선제설 UI와 기상·위험 연계

2026-09-20. 사용자 요청에 따라 명칭·캐릭터·분석 동선을 개편했다.

## 화면과 지역 선택

지역 바로가기(서울숲·남산·여의도)는 제거했다. 실제 지형·건물·수목 데이터는 유지한다. 지도를 옮기고 250m/500m/1km 크기를 골라 ‘이 주변 분석하기’를 누른다. 지도에서 위치 선택은 한 번 클릭 또는 드래그를 지원한다. 오른쪽은 위험 살펴보기, 그늘·일조, 기상 연계로 나눈다. 분석 시각은 한국시간 00:00~23:59이다.

## 현재 제공 범위

위험지점 GeoJSON을 브라우저 메모리에 읽어 검토할 수 있다. 서버 전송·영구 저장은 하지 않는다. 새로고침하면 자료를 다시 불러와야 한다. 위치 기호는 영향 반경을 뜻하지 않는다. 운영 자료는 현장 결빙 확인, 모델 우려, 판단 보류를 구분하며 테스트 파일은 보라색 테두리와 명시적 테스트 문구로 표시한다. 데이터가 없거나 오래되었다는 것은 안전하다는 뜻이 아니다.

관측 시각, 예보 발표/대상 시각, 품질 플래그, 유효기간, 근거, 공간 대표성, 모델 버전을 검증한다. 선택 시각보다 나중에 입수된 자료, 유효기간 밖 자료, 품질이 좋지 않은 자료는 판단 보류로 표시한다. 관측 결빙을 미래의 확정 상태로 표시하지 않는다. 6시간 유효기간·72시간 예보 범위·관측 확인 60분 제한은 초기 표시 계약의 보수적 정책이며 물리적 결빙 기준이 아니다.

기상청 자동 수집, 노면온도 추정 및 위험 산출 모델은 아직 연결하지 않았다. 그늘만으로 위험 점수를 만들지 않는다.

## 팀원에게 요청할 자료

[전달용 요청서](../app/public/guides/weather-request.txt)에 우선순위, 필드, 관측 주기, 기간, 파일 형식을 정리했다. 먼저 서울 실제 도로의 노면온도·습윤·결빙 관측을 확보할 수 있는지 확인한다. KMA 자체 또는 유관기관 공유 자료의 가용성을 별도 확인한다. AWS/ASOS 기온·습도·강수·적설·바람, 단기·초단기 예보, 일사·운량을 함께 받고 과거 결빙/비결빙 및 제설 이력으로 검증한다. 지면·초상온도는 도로 노면온도와 동일시하지 않는다.

시계열은 UTF-8 CSV/JSON, 지점 메타데이터는 GeoJSON, 원본 격자예보는 NetCDF/GRIB가 적합하다. 시간대·단위·누적 구간·결측·QC·센서 위치/높이·예보 발표 및 유효시각을 보존한다. 공개 배포 범위도 별도 확인한다.

권장 연결: 서버의 자료 수집/캐시 → 품질 검사 → 도로 구간별 분석 → 유효시각 있는 GeoJSON/API → 지도. API 키는 브라우저에 넣지 않는다. [현재 위험지점 계약](../app/public/guides/risk-contract.md)을 후속 서버 출력의 출발점으로 사용한다.

## 검토와 검증

Herdr의 claude-seoul에 읽기 전용 검토를 두 차례 맡겼다. 관측/예보 구분, 품질·대표성, 자료 시점, 테스트 기호, 예보 범위, 입력 없는 자료, 지도 스타일 복구 의견을 반영했다. API 목록에 없다는 이유만으로 노면 자료가 없다고 단정하는 의견은 채택하지 않았으며 공식 자료의 가용성 확인으로 정리했다.

로컬 테스트 42개 파일·238개 항목 통과 및 프로덕션 빌드 통과. 브라우저에서 범위 선택, 일조 계산, 테스트 위험파일 표시, 시각 변경에 따른 판단 보류 전환을 확인했다. UI 검증용 가상 파일은 저장소·배포에 포함하지 않는다.
