# 기존 작업 중단과 신규 과정 프로젝트 인계

작성일: 2026-09-18

후속 확정: 대상 서울시, 지도 Google Maps. 본 문서는 최초 분리 시점 기록이며 최신 수집 결과는 [05 문서](05-서울데이터-다운로드결과.md)를 따른다. 원본 빛길 서버는 사용자의 별도 실행 요청으로 다시 실행됐으며 원본 소스는 보존한다.

## 사용자 요청

현재 빛길 작업을 중단한다. AI 전문인재 과정에서 그동안의 내용을 기반으로 그늘·기상 데이터를 통합하여 위험지역을 안내하는 시스템을 만들고 싶으며, 새 프로젝트 폴더에 기존 내용과 구상을 담는다.

## 이번에 수행한 범위

- 원 프로젝트 파일 변경 없이 개발 중단. GPT가 실행했던 기존 Vite 서버도 중단.
- 코드·설정·테스트·가공 데이터·원천 CSV·과거 문서·CCTV 원본 엑셀·건물 원본 ZIP 복사.
- 외부 검수 기록 및 과거 단계별 실행 지시서를 reference/에 보관.
- 실제 API 비밀키, 설치 패키지, 빌드 결과, 원 프로젝트 Git 디렉터리는 복제하지 않음.
- 새로운 시스템의 기획·설계·데이터 확보 목록을 작성. 새 위험도 모델과 데이터 연동은 미구현.

## 기존 결과 요약

| 항목 | 보존 상태 |
|---|---|
| 건물 | 덕양구 63,882개 형상. 2026-09-09 자료 식별자. 메타상 대장 높이 채택 비율 21.61%, 나머지는 추정 |
| CCTV 원본 | 1,800개소·카메라7,549대 |
| 덕양구 대상 | 919개소·카메라3,713대 |
| 좌표 | 공식895 / 기존 건물 참고12 / 없음12 |
| 검토 필요 | 24개소: 연결 후 보류18 + 연결 미확정6 |
| 기본 지도 표시 | 철거5개 제외902개소 = 공공891 + 참고11 |
| 태양 | SunCalc1.9.0. 방위 변환·계절별 남중고도 등 기존 테스트 통과 |
| 일조 계산 | 기본4m 격자·10분 간격. 지형·수목·기상 미반영 |
| 과거 검증 | 앱29파일161테스트, Python importer25테스트, TypeScript/Vite 빌드 통과 |

과거 테스트 통과는 새 환경위험 시스템의 정확도나 현장 성능을 보증하지 않는다.
일조시간은 기하학적 계산 결과이며 관측 일사량이 아니다. `heightSource=measured`는 현장에서 직접 측정했다는 뜻이 아니라 기존 변환 규칙으로 대장 높이를 채택했다는 의미다.
CCTV 높이4.5m·카메라 방향배치는 표시용이며 원본 설치규격이 아니다.
SunCalc 태양 계산을 독립적인 정밀 기준과 전 범위 비교해 최대 오차를 측정한 상태는 아니다. 기존 테스트의 허용오차를 라이브러리의 보증 정확도로 해석하지 않는다.

## 논의한 데이터와 아이디어

1. 언덕·산·경사면: DEM으로 땅 높이를 만들고 건물·CCTV의 설치 지면을 맞춘다.
2. 건물·수목 포함 표면: 정밀 DSM 또는 LiDAR를 검토하되 덕양구 확보 가능성은 미확정.
3. 개별 가로수: 위치만으로 부족하며 수고·수관폭·수관하단·수종·계절별 투과율이 필요하다.
4. 기상: 기온·강수·습도·풍속·예보 등을 결합한다. 기상관측소나 예보격자의 값은 골목 실측값이 아니다.
5. 안내: 시간대별 환경위험 가능성과 원인, 데이터 시점·누락을 함께 제시한다.
6. AI: 확보 가능한 라벨과 교육과정 요구에 맞춰 역할을 확정한다. 물리계산·규칙·학습모델·LLM 설명을 구분한다.

## 아직 결정되지 않은 것

교육과정 기간·제출양식, 주 이용자, 첫 시범지역, 최우선 위험유형, 학습 라벨 확보 방법, 외부 서비스 운영 여부.
현재 기획은 덕양구 일부 구간에서 폭염/일사 노출과 결빙 가능성을 우선 검토하는 제안이다. 사용자 확정 요구로 간주하지 않는다.
침수·낙석·범죄위험은 각각 필요한 추가 자료와 검증이 다르므로 이번 기반 데이터만으로 산출하지 않는다.

## 과거 기록 읽는 법

`app/docs/`는 기존 빛길의 시간순 기록으로, 초기에 CCTV 위치가424개였던 기록과 후속895개 공식좌표 반영 기록이 함께 존재한다.
현재 수치는 `app/public/data/facilities/cctv_sites.meta.json` 및 `app/docs/reviews/public-cctv-gpt-review.md`를 기준으로 한다.
reference/gpt-review-history의 스크립트에는 과거 PC 절대경로가 남아 있을 수 있으므로 그대로 실행하지 않는다.
원본 스냅샷 검증 대상과 SHA256은 `reference/snapshot-manifest.json`에 기록했다.
