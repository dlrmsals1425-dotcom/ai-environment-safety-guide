## 1. 설계 전제

문서 01의 해석 원칙을 설계 제약으로 옮기면 다음과 같다. 이 제약은 구현 선택보다 상위다.

1. **산출물은 조건적 상대 등급이다.** 절대 위험도·확정 판정을 생성하는 경로를 설계에 두지 않는다.
2. **그늘은 계절에 따라 부호가 반대다.** 하계 지표와 동계 지표는 동일한 차폐 입력을 쓰되 **별도 지표로 분리**하며, 하나의 통합 "위험 점수"로 합산하지 않는다.
3. **관측소·격자 기상은 골목 실측이 아니다.** 기상 입력은 언제나 대표성 정보(거리·해상도·시점)와 함께 다룬다.
4. **미확보 입력은 0이 아니다.** 결측은 기본값으로 대체하지 않고 결측으로 전파하여, 결과에 품질 하락 또는 산출 보류로 나타난다.
5. **물리·규칙이 먼저다.** ML은 baseline이 존재하고 검증 분할이 갖춰진 뒤에만 투입한다.
6. **품질은 단일 서열이 아니다.** 자료·산출물의 품질은 4개 축으로 분리 표기한다(3.5항).

## 2. 전체 구성

```
[입력 계층]  ※ 대상: 서울특별시 (덕양구 자료는 레거시 참고, 합치지 않음)
  건물 형상·높이  (서울 695,754건 확보 / 높이 양수 43.9456%, 이상치 검수 필요)
  지형 DEM / 표면 DSM        (정밀분 미확보 — 전역분 공개 제한, 도로 지역분 목록상 공개·파일 미확보)
  수목 위치·수고·수관         (서울 가로수 257,235 · 공원사유지 178,390 · 보호수 346 확보, 2013년 자료)
  기상 관측·예보 시계열        (미확보)
  CCTV 등 지점 자료           (레거시 덕양구 자료만 있음, 서울 대상 아님)
        |
[계산 계층]
  1) 태양 기하 (시각별 고도/방위)
  2) 차폐 판정 (건물 → +지형 → +수목)
  3) 일조·그늘 시계열 (격자 x 시간)
        |
[결합 계층]
  4) 기상 시계열 결합 (기온·강수·일사)
  5) 지표 산출  A. 하계 노출 등급 / B. 동계 결빙 가능성 등급  ← 분리 유지
  6) 품질 표시 산출 (4개 축 각각 기록 → 결과에 동반 표기)
        |
[표현 계층]  ※ 지도 기반: Google Maps (표현 전용, 분석 입력 아님)
  지도 시간대 조회 · 근거 문장 · 한계 표기 · 미확보/보류 영역 표시
  (2차) 노출 저감 참고 경로
```

ML은 위 구조에서 **5)의 대안 산출기**로만 위치하며, 동일 입력·동일 검증 분할에서 규칙 baseline과 비교되는 형태로만 들어간다.

## 3. 계산 설계

### 3.1 태양 기하

- 기존 자산(SunCalc 1.9) 기반 계산을 재사용한다. 신규 개발 대상이 아니다.
- 확인된 기존 해상도: **4m 격자 / 10분 간격**. 초기 기준 해상도로 사용하되, 지형·수목 추가 후 연산량을 재측정해 조정 여부를 판단한다.
- 태양 위치 계산의 정확도와 **최종 그늘·지표 산출의 정확도는 별개**다. 전자를 근거로 후자를 주장하지 않는다.

### 3.2 차폐 판정 (단계적 확장)

| 차수 | 반영 요소 | 자료 상태 | 비고 |
|---|---|---|---|
| L0 | 건물만 | **확보** — 서울 **695,754건**(기준일 2026-09-09, EPSG:5186). 높이 양수 **305,753건(43.9456%)**, 0·음수 389,781, 결측 220, 최댓값 11,700m 이상치 존재 | 계산 방식은 동결된 `app/`(레거시, 덕양 63,882건)이 수행하던 수준과 같다. **덕양 수치·300m 상한 규칙을 서울에 그대로 적용하지 않는다** |
| L1 | 건물 + 지형 | **정밀분 미확보** — 서울 전역 DEM/DSM/LiDAR는 공개 제한, 도로 지역분은 목록상 공개이나 파일 미확보. VWorld 90m DEM은 거친 참고용 | 경사지 그늘 시각 보정. DSM 사용 시 건물 중복 가산 금지 |
| L2 | L1 + 수목 | **확보(정제 전)** — 서울 가로수 257,235건, 공원·사유지 178,390건, 보호수 346건. 수고·수관 필드 존재로 **근사 계산 가능** | 2013년 자료, 가로수 자료에 종로구 없음, 수고 이상치(최대 1,911) 정제 필요. 수관 형상·가지 하단·투과율이 근사값이라 정밀도·검증 한계가 큼 |

- 각 격자·시각의 결과에는 **차폐 차수(L0/L1/L2)** 를 함께 저장한다. 차수는 "반영 요소 완전성" 축의 표시값이다.
- **차수가 높다고 결과가 더 정확하다는 뜻은 아니다.** L2에도 수관 근사 오차·낙엽 시기·높이 추정 오차가 남는다. 차수는 **무엇을 반영했는지**를 알릴 뿐 정확도를 보증하지 않는다.
- L0 결과를 L2인 것처럼 제시하지 않는다. 가로수가 있는 구간은 L0/L1 상태에서 "하계 차폐 과소 추정 가능"으로 표기한다.

### 3.3 기상 결합

- 입력 후보: 기온, 강수·강설, 일사 관련 값의 시계열. **구체 항목과 제공 형식은 기상 API 확보 시점에 확정**한다(현재 미확보, 03 문서 W01~W03).
- 모든 기상값에 다음을 함께 보관한다: 출처 종류(관측/예보), 대표 지점까지의 거리 또는 격자 크기, 시간 해상도, **예보 발표시각과 대상시각의 구분**.
- 사후 관측값을 당시 예보처럼 학습·평가에 섞지 않는다.
- **골목 단위 보정을 임의로 만들지 않는다.** 미세기후 보정 필요성은 한계로 기술하고, 검증되지 않은 보정식을 산출물에 넣지 않는다.

### 3.4 지표 정의 (잠정)

#### A. 하계 노출 등급

- 개념: 선택 시간대에 대상 격자가 직달광에 노출된 정도와, 고온 조건이 겹친 정도의 **상대 등급**.
- 입력: 시간대별 일조 여부(차폐 차수 포함), 기온, 일사 관련 값.
- 출력: 구역 내 **상대 등급(예: 낮음/보통/높음)** + 품질 표시(4축) + 근거 요약.
- 금지: 열지수·온열질환 위험 진단, 체감온도 단정.

#### B. 동계 결빙 **가능성** 등급

- 개념: 일조가 장시간 닿지 않는 조건에서 기온·강수 이력이 겹칠 때, **노면 건조가 늦어질 수 있고** 재결빙 **가능성**이 상대적으로 높아지는 정도의 상대 등급.
- 입력: 시간대별/일간 누적 일조 시간, 최근 기온 이력, 강수·강설 이력, 차폐 차수.
- 출력: **가능성 등급(참고값)** + 품질 표시(4축) + 근거 요약 + 고정 고지 문구.
- 누락 요인 표기 필수: 노면 수분, 노면 온도, 배수, 제설 작업 여부는 입력에 없다. 기온 0℃ 이하만으로 결빙을 단정하지 않는다.
- 금지: 결빙 유무 판정, 발생 시각 예측, 사고 예측.

> 두 지표는 **합산·통합하지 않는다.** 계절·조건이 다르고 그늘의 의미가 반대이므로, 하나의 점수로 묶는 순간 원칙 2가 깨진다.

### 3.5 품질 표시 설계 (단일 신뢰도 점수 금지)

자료와 산출물의 품질은 **하나의 등급이나 자동 서열로 압축하지 않는다.** "정밀 자료가 항상 우월", "관측이 항상 예보보다 우월" 같은 고정 우열은 근거가 없다. 아래 **4개 축을 각각 기록하고 각각 표시**한다.

| 축 | 묻는 것 | 기록 항목 | 주의 |
|---|---|---|---|
| 반영 요소 완전성 | 어떤 차폐 요소까지 계산에 넣었는가 | L0 / L1 / L2, 미반영 요소 목록 | **높은 차수도 부정확할 수 있다.** 완전성은 정확도가 아니다 |
| 측정 품질 | 값을 어떻게 얻었는가 | 대장 제공값 / 층수·용도 추정 / 관측 / 모델 산출, 오차 성격 | 건물 높이는 대장 채택 21.61% + 추정(실측 아님)임을 항상 함께 표기 |
| 시점 적합성 | 조회 시각과 자료 시점이 맞는가 | 자료 기준시각, 예보 발표시각·대상시각, 갱신일 | **미래 시각 조회에는 예보가 적합하다.** 과거 시각에는 관측이 적합하다. 방향이 자료 종류가 아니라 **조회 시점**으로 결정된다 |
| 공간 대표성 | 값이 대표하는 공간 범위는 어디인가 | 관측소 거리, 예보 격자 크기, 계산 격자 해상도(4m) | 세밀하게 보간해도 원자료 대표성은 향상되지 않는다 |

운영 규칙:

- 결과 화면에는 4축을 모두 보존하되, 사용자가 놓치지 않도록 **가장 취약한 축을 전면에 함께 노출**한다.
- 이 "가장 취약한 축 우선 노출"은 **검증 전 보수적 초안 규칙이며, 확률적 신뢰도나 오차 확률이 아니다.** 검증 자료가 쌓이면 축별 가중과 표시 방식을 재설계한다.
- 결측 입력이 있으면 해당 지표는 **산출 보류 또는 미확보 표기**로 처리한다. 인접 값으로 메우지 않는다.
- 지점 자료(CCTV 등)는 좌표 획득 방식(공공 좌표 매칭 895건 / 참고 좌표 12건 / 좌표 없음 12건, 검토 대상 24건)을 **측정 품질·공간 대표성 축에 기록**한다. 이를 단일 점수로 환산하지 않는다.

## 4. 표현 규칙

- 각 결과는 **값 + 품질 표시(4축) + 근거 + 한계** 4요소를 항상 함께 표시한다.
- 허용 표현: "가능성", "상대적으로 높음", "참고", "미확보", "판정 보류", "과소 추정 가능", "건조가 늦어질 수 있음".
- 금지 표현: "안전", "안전 경로", "결빙 있음", "노면이 마르지 않는다"(단정), "위험 지역 확정", "예측 정확도 OO%"(5.1 조건 충족 전).
- 고정 고지: "본 산출물은 환경·기상 요인에 대한 참고 정보이며, 범죄 예측이 아니고 안전을 보장하지 않습니다."

## 5. ML 투입 조건과 검증 설계

### 5.1 투입 전 필수 조건 (모두 충족해야 학습 시작)

1. **규칙 기반 baseline이 완성**되어 동일 산출 형식으로 결과를 내고 있을 것.
2. **라벨 정의가 문서화**되고, 최소 수량이 실제로 수집되어 있을 것.
3. **시공간 분리 검증 분할이 사전에 고정**되어 있을 것(학습 시작 후 변경 금지).
4. 라벨 수집 과정의 편향(수집 지점 쏠림, 관측 시간대 쏠림)이 기록되어 있을 것.

> 위 4개 중 하나라도 미충족이면 ML 산출물은 **"미검증 시제품"** 으로만 표시하며, **정확도·성능 수치를 보고하지 않는다.**

### 5.2 라벨 계획 (초안, 03 문서 L01)

- 후보 라벨: 현장 점검 시 기록한 노면 상태 관측(건조/습윤/결빙 흔적), 시간·위치가 기록된 현장 사진, 그늘 여부 실측, 표면온도 측정값.
- 수집 원칙: 위치·시각·측정 방법을 함께 기록하고, 개인 식별 정보가 들어가지 않도록 촬영·기록 규칙을 사전에 정한다(합법적 수집·비식별화).
- 수량·방법은 현장 접근 가능 범위 확인 후 확정한다. **현재 확보된 라벨은 없다.**

### 5.3 검증 분할 (시공간 분리)

| 분할 축 | 방법 | 목적 |
|---|---|---|
| 공간 | 인접 격자가 학습·검증에 섞이지 않도록 **블록 단위 홀드아웃**(구역 통째로 분리) | 인접 격자 유사성에 의한 성능 과대평가 차단 |
| 시간 | 학습 기간과 검증 기간을 **겹치지 않게 분리**, 검증 기간은 학습 이후 구간 | 같은 기상 사건이 양쪽에 들어가는 누수 차단 |
| 사건 | 동일 강수·한파 사건 구간은 한쪽에만 배정 | 사건 단위 누수 차단 |

- 무작위 격자 분할은 **사용하지 않는다**(공간 자기상관으로 성능이 부풀려진다).
- 분할 정의는 학습 전에 파일로 고정하고, 변경 시 이력을 남긴다.
- 가능하면 수목이 많은 구간/적은 구간, 경사지/평지를 모두 포함해 조건별 성능 차이를 본다.

### 5.4 비교 보고 형식

ML 결과는 아래 형식으로만 보고한다.

```
지표: (A 하계 노출 / B 동계 결빙 가능성)
검증 분할: 공간 블록 X, 기간 Y (사전 고정, 변경 이력 없음)
라벨: 정의 / 수량 / 수집 편향 기록
baseline(규칙): 결과
ML: 결과
차이: 동일 분할 기준 비교값
한계: 미확보 입력, 품질 4축 표시
```

baseline이 없거나 분할이 사후 조정되었으면 **그 결과는 보고하지 않는다.**

### 5.5 LLM 역할과 경계

- 허용: 산출된 등급·근거·한계를 **읽기 쉬운 문장으로 설명**, 문서 초안 정리, 용어 일관성 점검.
- 금지: 위험 등급 생성·보정, 결측 구간 보간, 수치 추정, 출처 없는 링크·수치 생성.
- 검증: LLM이 만든 설명 문장은 **원 수치와 대조하는 점검 절차**를 거친 뒤 사용한다.

## 6. 단계별 진행과 게이트

각 단계는 **진입 조건 → 산출물 → 평가 → 시연** 순으로 정의한다. 교육과정 기간이 확인되지 않았으므로 주차를 배정하지 않으며, **게이트 충족 여부로만 진행**한다.

### S0. 자료 정리·기준선 확인

- 진입 조건: `app/` 동결 완료, [03-데이터와-출처목록.md](03-데이터와-출처목록.md)와 루트 README의 무결성 기록 작성 완료.
- 산출물: 보유/미확보 자료 대장(03 문서 ID 기준), 동결 시점 기능과 신규 계획의 분리표, 기준선(L0 그림자 계산) 재현 기록.
- 평가: 보유 수치가 manifest·profile과 일치하는가 — **서울**: 건물 695,754(높이 양수 305,753 / 43.9456%), 가로수 257,235, 공원·사유지 178,390, 보호수 346. **레거시(덕양, 서울 산출물 아님)**: 건물 63,882(대장 높이 채택 21.61%), CCTV 919 = 895 + 12 + 12(검토 24), TS 161 · Python 25 테스트 상태.
- 시연: 자료 대장과 기준선 재현 결과 보고.
- **게이트**: 미확보 항목(DEM·DSM·수목·LiDAR·기상 API·도로망·라벨)이 명시적으로 목록화되어 있어야 S1 진입. 원본 `../cpted-sunmap`이 무변경 상태인지 확인.

### S1. 물리 차폐·일사 계산 확장 (L1 → L2)

- 진입 조건: DEM 확보 시 L1. 개별 수목 위치·수고·수관 또는 영상 기반 자료 확보 시 L2 근사.
- 산출물: 지형(및 수목) 반영 그림자·일조 시계열, 차수별 결과 차이 비교표, 근사 가정 목록(수관 형상·가지 하단·투과율).
- 평가: **골든 케이스 검증** — 단순 기하(단일 건물·단일 경사)에서 계산 그림자가 기대 방향·길이와 일치하는가. 차수 상승 시 변화가 물리적으로 설명되는가.
- 시연: 동일 지점·동일 시각에서 L0 / L1 / L2 결과를 나란히 보여주고 차이를 설명.
- **게이트**: DEM 미확보여도 **S2로 진행한다.** 이 경우 L0 상태를 유지하고 "지형 미반영"을 명시하며, 경사·구릉 구간은 판정 보류로 표기한다.

### S2. 기상 결합과 지표 정의

- 진입 조건: 지표 정의 착수는 무조건 가능. **산출 실행은 기상 API 확보 시**(미확보면 정의·스키마까지 완료 후 대기).
- 산출물: 지표 A·B 산출식과 등급 경계 문서, 결측 전파 규칙, 품질 4축 스키마, 기상 대표성 메타데이터 스키마.
- 평가: 결측 주입 시험 — 기상값을 일부러 비웠을 때 결과가 **임의 기본값으로 채워지지 않고** 보류·미확보로 표시되는가. 예보/관측 시점 구분이 유지되는가.
- 시연: 동일 구간을 여름 조건 / 겨울 조건으로 바꿔 보여주고, **같은 그늘이 반대로 해석되는 것**을 설명. DEM 미확보 상태라면 **L0 + 기상 기반의 제한된 기준선 시연**으로 수행하고, 지형 미반영·구릉지 보류를 화면에서 함께 보여준다.
- **게이트**: 두 지표가 통합 점수로 합산되지 않고 분리 유지되는지, 품질 4축이 결과에 동반 표기되는지 확인.

### S3. 규칙 기반 baseline 확립

- 진입 조건: S2 지표 정의 완료.
- 산출물: 학습 없이 동작하는 규칙 baseline, 근거 문장 생성 규칙, 재현 절차서.
- 평가: 재현성(동일 입력 → 동일 출력), 설명 가능성(각 등급의 근거가 입력값으로 추적되는가), 표현 규칙 준수(금지 표현 미사용).
- 시연: 임의 지점 3곳을 골라 등급과 근거·한계를 즉석에서 설명.
- **게이트**: baseline이 없으면 S4의 ML 트랙에 진입하지 않는다.

### S4. 검증·라벨·(조건부) ML

- 진입 조건: 5.1의 4개 조건 전부 충족.
- 산출물: 라벨셋과 수집 기록, 사전 고정된 시공간 분할 정의, baseline 대비 비교 보고서.
- 평가: 누수 점검(분할 경계 확인), baseline 대비 개선 여부, 편향 기록의 존재.
- 시연: **분할 설계부터 먼저 설명한 뒤** 결과를 제시. 결과만 먼저 보여주지 않는다.
- **게이트**: 조건 미충족 시 ML 산출은 "미검증 시제품"으로만 전시하고 **수치 미보고**. 이 경우 S4는 "검증 설계 산출물"로 종료해도 정상 완료로 본다.

### S5. 시연·문서화

- 진입 조건: S3(최소) 완료.
- 산출물: 시연 시나리오, 한계 기술서, 자료 목록·무결성 기록 최종본, (2차 범위 달성 시) 노출 저감 참고 경로 데모.
- 평가: 아래 7항 루브릭.
- 시연 구성(순서): ① 문제와 원칙 → ② 자료 보유/미확보 → ③ 계산 차수별 차이 → ④ 두 지표와 반대 해석 → ⑤ 검증 설계 → ⑥ 한계와 다음 과제.
- 소요 시간: **약 15~20분은 본 문서의 제안값이다. 교육과정이 요구하는 발표 시간은 아직 확정되지 않았으며**, 확인 후 구성을 조정한다(시간이 짧으면 ③④를 축약하고 ①⑤⑥을 유지한다).

## 7. 평가 루브릭

| 항목 | 확인 방법 | 합격 기준 |
|---|---|---|
| 정직성 | 화면·보고서에 미확보/보류/취약 축 표기 존재 여부 | 미확보 영역이 빈 상태 또는 명시 표기로 나타남 |
| 재현성 | 동일 입력 2회 실행 | 산출 동일, 절차서로 제3자 재현 가능 |
| 물리 타당성 | 골든 케이스 대조 | 기대 방향·길이와 일치, 불일치 시 원인 기술 |
| 지표 분리 | 지표 A·B 산출 경로 점검 | 통합 점수 없음, 계절별 반대 해석 설명 가능 |

| 검증 설계 | 분할 정의 파일과 이력 | 사전 고정·변경 이력 확인, 무작위 격자 분할 미사용 |
| 표현 절제 | 금지 표현 검색 | "안전 보장", "결빙 확정", 단정형 "마르지 않는다", 미검증 정확도 수치 0건 |
| 범위 준수 | 산출물·저장소 점검 | 범죄 예측·개인정보 요소 0건, 원본 `../cpted-sunmap` 무변경, 개발은 `app/`에서만 |

## 8. 중단·축소 기준

- 기상 API를 확보하지 못하면 **물리 산출물 + 지표 정의 + 검증 설계**로 범위를 축소해 종료한다(정상 종료로 간주).
- DEM을 확보하지 못하면 **L0 + 기상 결합의 제한된 기준선**까지 수행한다. 지형 미반영을 명시하고 경사·구릉 구간은 판정 보류로 처리한다.
- 수목 자료를 확보하지 못하면 **하계 지표를 "가로수 구간 해석 보류"** 조건부로만 제시한다. 개별 좌표·수고 자료만 확보되면 LiDAR 없이도 근사 계산으로 확장하되, 근사 가정과 검증 한계를 함께 기술한다.
- 라벨을 확보하지 못하면 **ML 트랙을 수행하지 않고** 검증 설계 문서로 대체한다.
- 어느 경우에도 **범위를 줄이되 표기 원칙은 줄이지 않는다.**

## 9. 미해결 항목 (확인 필요)

1. 교육과정 기간·중간 평가 시점·**발표 요구 시간** — 확인 후 단계 배치와 시연 길이 확정.
2. **서울 내 시범구역** — 임의로 확정하지 않는다. 선정 기준은 04 문서 9항, 결정은 사용자 몫.
3. 기상 자료 획득 경로와 제공 항목·해상도·시점 구분 방식.
4. 정밀 표고 확보 가능성 — 서울 전역분은 공개 제한, 도로 지역분은 목록상 공개이나 경로 탐색 중(04 문서 3.3).
5. Google Maps 연동 조건(키·Map ID·3D 경로)과 서울 커버리지 — 연동 전 미검증(04 문서 0·5항).
6. 현장 라벨 수집의 접근 가능 범위와 기록 규칙.
7. 2차 범위(노출 저감 참고 경로)의 수행 여부와 도로망 자료 확보.

## 10. 작업 원칙 (현 시점)

- **코드 개발은 아직 착수하지 않는다.** S0 게이트 통과 후 시작한다.
- 원본 `../cpted-sunmap`은 **보존**하며 수정하지 않는다.
- 본 프로젝트의 `app/`은 **현재 시점으로 동결한 출발점**이며, **이후 모든 개발·수정은 `app/`에서만** 진행한다. 변경을 원본으로 되돌려 반영하지 않는다.
- 자료 목록·출처·한계는 [docs/03-데이터와-출처목록.md](03-데이터와-출처목록.md)를 정본으로 하며, **본 문서는 확인되지 않은 URL을 생성하지 않는다.**
