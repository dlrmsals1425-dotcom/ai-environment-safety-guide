# 선제설 — 서울 겨울길 환경안전 지도

AI 전문인재 과정 팀 프로젝트. 건물·지형·수목·기상 정보를 함께 살펴보고 환경위험 안내로 확장하기 위한 지도 기반 프로토타입입니다.

현재는 **서울 건물·추정 지형의 그늘/일조 계산, 3D 수목, 제설전진기지 표시**까지 구현했습니다. 선제설 UI와 외부 위험지점 GeoJSON 검토 기능을 제공합니다. 개별 수목 차폐, 기상 자동 연동, 결빙·위험도 산출 모델은 아직 구현하지 않았습니다.

## 실행

Node.js 22 LTS가 필요합니다. 공개 저장소이므로 누구나 Clone할 수 있습니다. 코드 수정 권한은 초대한 팀원에게만 부여합니다.

```sh
git clone https://github.com/dlrmsals1425-dotcom/ai-environment-safety-guide.git
cd ai-environment-safety-guide/app
npm ci
npm run dev
```

첫 실행 시 **서울숲·남산·여의도 주변의 실제 건물·수목 공개자료 샘플**이 자동 준비됩니다. 구 경계·제설함은 서울 전체가 포함되지만, 구 전체 건물·수목 분석에는 아래 전체 데이터 설치가 필요합니다. 앱이 출력한 주소에서 지도를 옮긴 뒤 `이 주변 분석하기`를 누르세요. 현재 지도에는 API 키가 필요하지 않습니다. 전체 데이터가 이미 설치된 개발 PC에서는 해당 자료를 그대로 사용합니다.

```sh
npm test -- --run
npm run build
npm run data:check
```

팀 저장소에는 약 28MB의 시연 자료만 포함합니다. 서울 전체 런타임 데이터(약 607MiB)는 Releases의 별도 ZIP을 설치하세요. 설치 방법과 SHA256 확인은 [팀 협업 시작](docs/10-GitHub-팀협업-시작.md)에 있습니다.

## 무엇을 볼 수 있나요?

- 서울 25개 자치구 선택·경계 토글·구 전체 보기.
- 제설함 10,435개: 구별 필터, 번호·관리기관·주소 검색, 지도 클릭 상세.
- 선택 구의 위험지점 필터와 구 전환 시 이전 분석 결과 제거.
- [자치구·제설함 자료 및 잔상 개선 기록](docs/14-자치구-제설함-영역전환.md).

- MapLibre + OSM 지도 위의 추정 지형과 3D 건물.
- 날짜·시간에 따른 지면 그늘. 조작 중 기본 4m 미리보기, 멈추면 기본 2m/경계 0.5m 재계산.
- 관심구역 하루 일조 가능시간: 4m 격자·10분 간격.
- 수고·수관폭에 따른 간략 3D 수목과 크기 미상 기호, 클릭 속성 조회.
- 제설전진기지 86개 검색·구분 필터·위치 이동.

그늘을 보려면 250m·500m·1km 중 크기를 골라 `이 주변 분석하기`를 누르거나, `지도에서 위치 선택`으로 클릭·드래그합니다. 시간 변경 중 이전 결과가 유지될 수 있으므로 지도 아래의 실제 표시 시각을 확인하세요.

## 정확도와 미구현 범위

**0.5m는 경계 계산 간격이며 현장 정확도가 아닙니다.** 지면은 Copernicus 약 30m급 DSM에서 가공한 추정값이고, 건물은 단일 높이 프리즘입니다. 대장 높이·층수 추정이 섞여 있으며 높이 미상 건물은 제외합니다. 원천 지면 오차, 좁은 그늘 누락, 지붕 단차/곡면, 수목·구름 차폐 등은 한계로 남습니다.

수목은 2013 공개 자료이며 현재 개체를 정밀 복원한 모델이 아닙니다. 제설기지 위치는 원천 좌표의 단위·투영법을 추론한 참고값입니다. 시설 위치나 그늘을 곧바로 위험도·안전 등급으로 해석하지 않습니다.

## 저장소 구조

```text
app/src/          지도·계산·UI·테스트
app/team-data/    Clone 후 바로 실행할 수 있는 시연용 공개자료
app/tools/        실행 전 자료 준비·검사
app/vercel.json   Vercel 빌드 설정 (Root Directory: app)
docs/             기획·설계·변경 이유·협업/배포 안내
tools/            원천 전처리·검증·전체 자료 설치 도구
data-catalog/     자료 출처·수량·전체 배포 ZIP 체크섬
.github/          CI·이슈 양식·PR 양식·코드 검토 담당
```

원본 자료, 서울 전체 가공 데이터, 개인 작업 기록, `.env`, 빌드 산출물은 Git에서 제외합니다. 원본 빛길 프로젝트는 별도로 보존하며 이 저장소에 합치지 않습니다.

## 협업과 배포

- `main`: 팀 공유·Vercel Production 기준.
- `develop`: 다음 버전의 개발 작업.
- `feature/*`, `fix/*`: 개인 작업 후 PR로 `develop`에 반영.
- GitHub Actions가 테스트와 시연 데이터 빌드를 확인합니다.
- Vercel 운영 배포는 공개 Release의 서울 전체 자료를 SHA256 검증 후 준비합니다. `main`에 변경을 합치면 연결된 Vercel 프로젝트가 배포합니다. 로컬 기본 실행은 가벼운 3개 구역 시연 자료를 유지합니다.
